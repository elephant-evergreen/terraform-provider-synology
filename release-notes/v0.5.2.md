## Upgrade notes

Existing configurations and state need no changes.

## Fixes

- Read-only DSM calls now re-authenticate once and retry when the session expires (106, 107, or 119). A write that hits an expired session returns an error without a retry, because its outcome may be uncertain. Concurrent expiries share one login.

## Compatibility

Fixture tests cover the new behavior. Hardware writes remain experimental: read and import behavior is verified on DSM 7.1.1, and write acceptance requires the dedicated environment described in [testing](https://github.com/elephant-evergreen/terraform-provider-synology/blob/v0.5.2/docs/testing.md#write-acceptance-environment).
